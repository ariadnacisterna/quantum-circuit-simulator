# quantum-circuit-simulator

> 🚧 Work in progress — full documentation coming in v1.0

Interactive quantum circuit simulator built with Next.js 14 and FastAPI + Qiskit.
Designed as an open source university demo project.

## Stack

- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Python, FastAPI, Qiskit, Qiskit Aer
